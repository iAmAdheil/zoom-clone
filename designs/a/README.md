# Design A: Zoom web client copy

A static Next.js + Tailwind mockup. It uses mock data only. There is no backend.

```bash
npm install
npm run dev      # http://localhost:3000
npm run build
npm run lint
```

- Start at `/signin`, `/` or `/meeting/8123456790`.
- Design tokens: `src/styles/tokens.css`.
- Mock data: `src/lib/mock.ts`.
- Research and decisions: `DESIGN_NOTES.md`.
- Screenshots: `screenshots/` (desktop 1440x900, tablet 834x1112, phone 390x844).
